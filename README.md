# Freelance OS

Quote, track and set aside tax in minutes. Built for freelancers paid across borders (Kenya first).

- `src/calculator.html` free quote builder (GitHub Pages)
- `src/lib/calc.js` money logic, no UI, tested
- `src/lib/rates.json` fees and rates, each to be verified before use
- `docs/` architecture, AI ethics, release checklist

## Run tests
`npm test`

## Rules
Never commit paid links, API keys or client data. Estimates only, not tax advice.
