# AI ethics rules
- Off by default. Explicit consent. Preview exactly what is sent.
- Never send client names, phones or emails. Replace with Client A, restore locally.
- AI proposes, the user confirms. No sending, no moving money, no filing taxes.
- Pasted text is data, never instructions (prompt injection).
- Never state a tax rate from memory. Read the rate cell and its verified date.
- Label AI output. Financial text says: estimate, not advice.
- No prompt logging. No false urgency or threats in reminders.
- The product must work fully with AI off.
- Kenya DPA 2019: cloud servers outside Kenya count as cross-border transfer. Check ODPC guidance.
